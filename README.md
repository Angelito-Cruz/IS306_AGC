\## Cloud Computing Concepts

\- What is cloud computing?

&#x09;Cloud computing is the delivery of computing resources such as servers, storage, databases, networking, and application platforms over the internet.



\- One possible benefit:

&#x09;Cloud computing allows user to access files, applications, and computing resources over the internet without needing to maintain all the required infrastructure themselves.



\- One possible risk or limitation:

&#x09;Cloud services depend on the internet connectivity and may expose data to security risks if accounts, permission, or stored information are not properly protected.



\- Difference between uploading code and deploying an application:

&#x09;uploading code to GitHub sores source files and version history in a remote repository. Deploying an application makes it available for users to access through a hosting or runtime service. Uploading code alone does not automatically make an application live.
